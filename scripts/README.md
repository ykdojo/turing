# Turing Script Utilities

This directory contains utility scripts for the Turing project.

## GeminiStreamingSDK Demo

A demonstration script that showcases the streaming capabilities of the GeminiStreamingSDK.

### Features

- Simple command-line interface
- Demonstrates streaming text responses in real-time
- Shows tool calling with a calculator example
- Visualizes the streaming process with detailed output

### Running the Demo

```bash
# Make sure you have a GEMINI_API_KEY in your environment or .env file
./scripts/run-streaming-demo.sh
```

### Example

The demo runs automatically and showcases:
1. A simple text streaming example
2. A calculator tool call example using "What is 123 * 456 divided by 2?"

### Prerequisites

- Node.js 18+
- A valid Gemini API key
